Autentikasi

Tukarkan username dan password menjadi JWT di POST {{ api_prefix }}/auth/token, lalu kirim token pada header Authorization: Bearer <token>. 

curl -s -X POST http://127.0.0.1:8080{{ api_prefix }}/auth/token \
  -H 'Content-Type: application/json' \
  -d '{"username":"budi01","password":"password"}'

Token berlaku 30 menit pada level patched. Level latihan lain memakai secret lemah dan tidak memeriksa kedaluwarsa.

Contoh pemakaian

TOKEN=$(curl -s -X POST http://127.0.0.1:8080{{ api_prefix }}/auth/token \
  -H 'Content-Type: application/json' \
  -d '{"username":"budi01","password":"password"}' | python -c 'import sys,json;print(json.load(sys.stdin)["access_token"])')

curl -s http://127.0.0.1:8080{{ api_prefix }}/balance \
  -H "Authorization: Bearer $TOKEN"

curl -s "http://127.0.0.1:8080{{ api_prefix }}/transactions?limit=5" \
  -H "Authorization: Bearer $TOKEN"

Parameter opsional: account_id pada balance/transactions, limit (1–100) pada transactions, dan user_id pada profile.
